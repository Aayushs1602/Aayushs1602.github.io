## 🌐 Local Development & Hosting

### Option 1: View Locally
Simply open `index.html` in any modern web browser:
```bash
# On Windows PowerShell:
Start-Process index.html
```

### Option 2: Deploy with GitHub Pages (Free)
1. Go to your repository settings on GitHub: **Settings** $\rightarrow$ **Pages**.
2. Under **Build and deployment** $\rightarrow$ **Source**, select `Deploy from a branch`.
3. Choose `main` branch and `/ (root)` folder, then click **Save**.
4. Your site will be live at: `https://aayushs1602.github.io/portfolio/`
